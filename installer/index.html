ComfoAir Q firmware

Puts a Zehnder ComfoAir Q ventilation unit on your network over its ComfoNet (CAN) bus, with MQTT for Home Assistant, a REST API and its own web interface. One file for everyone: Wi-Fi, the broker and the password are set in the browser after installing. Version @VERSION@.

Not yet accepted on a real unit. It builds and its host tests pass, but the hardware-verification scenarios are still being worked through. Treat a first install as a bring-up, and keep the USB cable at hand.

Install

M5Stack NanoC6

ESP32-C6 · 4 MB flash · CAN on the Grove port

Needs Chrome or Edge on a desktop computer. Needs an https:// page (or localhost).

Before you click

  • Use Chrome or Edge on a desktop computer. Installing needs Web Serial, which Firefox, Safari and phones do not have.
  • Connect the NanoC6 with a USB-C cable that carries data, not only power.
  • In the port list, pick the entry called USB JTAG/serial debug unit (/dev/cu.usbmodem… on a Mac, a COM port on Windows). The chip has USB built in, so there is no driver to install.
  • If no port appears, or connecting fails: unplug the board, hold its button while you plug the cable back in, then release it and try again. That starts the chip in download mode. When the install finishes, unplug and replug without touching the button — a board started with the button held stays in download mode and looks dead.

Your settings

The installer asks whether to erase the device first. Leave “Erase device” unticked to keep everything: Wi-Fi, the web password, the broker and the other settings live in a part of the flash this install does not write. Tick it for a clean start — a board that ran other firmware before, or one whose settings you want gone.

After it installs

  1. A device that has no Wi-Fi stored opens its own setup network, comfoair-xxxx, where xxxx is four hex digits unique to the board. It is open (no password). Join it from a phone or laptop and open http://192.168.4.1 in a browser — any address you type leads there. The setup network stays up for about 15 minutes, longer while you are using it; if it is gone, power the board off and on.
  2. Choose your Wi-Fi and save. The device joins it and is then at its address on your network, or at http://comfoair-xxxx.local.
  3. In Settings, set a password, then enter the MQTT broker and turn on Home Assistant discovery. Home Assistant finds the unit by itself; no integration is needed.

The installer will not offer “Connect to Wi-Fi”: this firmware does not speak Improv Wi-Fi yet, so Wi-Fi is always set through the setup network above.

Updating later

No cable needed. Download @OTA_BIN@ and upload it on the device's own Update page. Updates require the web password to be set. If the new version fails to start, the device goes back to the previous one by itself.
